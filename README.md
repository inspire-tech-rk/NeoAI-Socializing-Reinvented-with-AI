# NeoAI: Socializing Reinvented with AI 🚀

A full-stack AI-powered social media application built using the MERN stack.

## ✨ Features

- User Authentication & Authorization
- Create Posts
- Like & Comment System
- Reels & Stories
- Real-time Messaging
- AI Features
- JWT Authentication

## 🛠 Tech Stack

### Frontend
- React.js
- Axios
- CSS

### Backend
- Node.js
- Express.js
- MongoDB
- JWT

## 📂 Project Structure

```plaintext
client/   → Frontend
server/   → Backend
```

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/your-username/NeoAI-Socializing-Reinvented-with-AI.git
```

### Frontend Setup

```bash
cd client
npm install
npm start
```

### Backend Setup

```bash
cd server
npm install
npm start
```

## 🔐 Environment Variables

Create `.env` inside server folder:

```env
MONGO_URI=your_mongodb_url
JWT_SECRET=your_secret
PORT=5000
```
